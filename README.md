# 봉쇄 도시 탈출(가제) 포트폴리오

Godot 4로 만든 탑다운 파밍·탈출 게임 프로토타입의 포트폴리오 사이트입니다.

- 사이트: https://jun-124242.github.io/lockdown-city-escape/
- Windows 실행파일: [AIGame_Windows.zip](https://github.com/Jun-124242/lockdown-city-escape/releases/latest/download/AIGame_Windows.zip) (Windows 10/11 64비트, Vulkan 지원 그래픽)

압축을 풀고 `AIGame.exe`를 실행합니다. 서명하지 않은 실행파일이라 SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
